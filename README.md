# WRB-TV Universal Web Player 6.0

Projeto refeito do zero. Não depende do painel WRB-TV.

Entrada: Xtream Codes, URL M3U/M3U8 ou arquivo M3U.

Xtream usa a Player API: autenticação, categorias, canais, filmes e séries. A API documenta `player_api.php`, `get_live_streams`, `get_vod_streams`, `get_series` e `get_series_info`.

Para publicar no Netlify, envie a pasta raiz deste projeto. O site é publicado de `public/` e a função fica em `netlify/functions/`.

Use apenas listas e acessos autorizados.
